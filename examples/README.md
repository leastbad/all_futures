# Examples

Small, copy-pasteable sketches of the patterns people actually ship. The long-form Beast Mode walkthrough still lives in [Faceted Search](faceted-search.md).

| Example | What it shows |
|---|---|
| [Faceted Search](faceted-search.md) | Filter / paginate / sort like Beast Mode |
| [Multi-step form](multi-step-form.md) | Persist invalid state across steps |
| [Versioned draft](versioned-draft.md) | History + `RecordStale` |
| [Embedded associations](embedded-associations.md) | `embeds_many` / lazy load after find |

Runnable Ruby for several of these also lives under [`examples/code/`](code/) in the repo if you want something to `ruby`-execute against a local Redis.
